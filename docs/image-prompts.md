# dsh-quota-pets 形象出图提示词（给 Codex / 图像生成 AI）

出图后把 PNG 重命名扔进本包 `assets/` 目录（见 assets/README.txt），
页面 30 秒内自动换装，无需刷新。先出 4 张基础形象即可，状态变体可选。

## 统一风格规范（每条提示词开头都带这段）

> Q版娘化角色立绘，2.5头身迷你比例，大头圆脸，大眼睛有高光，腮红，
> 温柔治愈系日系卡通画风，线条干净圆润，色彩柔和明亮，
> 全身可见，面向镜头站立，自然微笑，
> 纯色透明背景（alpha通道），竖构图，全身不裁切，脚下留少量空间，
> 主体居中占画面 85%，高分辨率 PNG 1024×1024 以上

## 可选：状态变体（想出全套时用，基础形象 + 差异描述）

每只可选出 3 张变体，命名 `deepseek.warn.png` / `deepseek.critical.png` /
`deepseek.work.png`（其余角色同理）：

| 变体 | 文件名后缀 | 在基础形象上追加的描述 |
|---|---|---|
| 焦虑 | `.warn.png` | 眉头微皱担心的表情，头顶一滴大汗珠，双手绞在胸前，身体微微前倾不安 |
| 躺平 | `.critical.png` | 累瘫了仰面躺倒，眼睛变成><，浑身无力，旁边飘着「没电了」的空电池图标 |
| 干活 | `.work.png` | 一脸专注干劲十足，撸起袖子，双手快速敲迷你键盘，头顶冒出决心的小火苗 |

## 出图检查清单

- [ ] 透明背景（不是白底！生成后如带白底需抠图）
- [ ] 全身在画面内，头不被裁
- [ ] 竖构图 1:1 或 2:3，脚底留少量空间
- [ ] 四只画风一致（同一会话/同一风格种子出图）
- [ ] 命名正确：`deepseek.png` `kimi.png` `glm.png` `minimax.png`
