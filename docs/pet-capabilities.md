# dsh-quota-pets 桌宠能力清单

> 给形象/动作设计用的对照表：桌宠现在「会什么、什么条件触发、表现在哪」。
> 出图的硬性规格（尺寸、命名、字节预算、透明角）**以
> [`pet-contract.md`](pet-contract.md) 为准**，本文只描述行为。
> 本文对应 v0.3.0 代码（`lib/client.js`）。

## A. 显示规则

- **只显示当前模型那只**：模型名 / provider 用 `PROVIDER_UI` 里的正则匹配
  到宠物（`glm` / `minimax` / `kimi` / `deepseek` / `mimo`）。
- 切模型时旧宠淡出、新宠淡入（0.25 s）。
- 全新的空白对话、或模型匹配不上任何一家时，**不显示宠物**。

## B. 动作状态（图内动画，需要美术出图）

每只宠物一态一文件：`assets/<petId>/<state>.webp`（动画）+ 静态兜底
`<state>.png` 或 `<state>-static.webp`。优先级从高到低：

| 优先级 | 状态 | 触发条件 | 持续 | 角标 |
|---|---|---|---|---|
| 1 | `working` | 当前会话正在运行 | 直到运行结束 | ⚡ |
| 2 | `error` | 本会话最近一次运行出错（宿主判定） | 直到本会话下一次运行开始；切换会话时清除 | ❌ |
| 3 | `done` | 运行正常结束（宿主判定；宿主不可用时客户端兜底：运行 ≥ 4 s） | 约 3 s 后回到 idle | ✅ |
| 4 | `sleeping` | 10 分钟没有运行、也没有与宠物交互 | 直到被唤醒 | 💤 |
| 5 | `idle` | 其余情况 | — | 按额度压力 |

- `done` / `error` 是一次性动作：每次触发会重新播放，播完停在最后一帧。
- 运行中额外加金色光晕（CSS `drop-shadow`）。
- 系统开启「减少动态效果」时只用静态图。
- 缺图回退链：`<state>` 动画 → `<state>` 静态 → `idle` 静态 → `idle`
  动画 → 内置 SVG 占位。
- **过渡片段**（可选，contract §6.1）：`<from>-to-<to>.webp`，状态切换时先播一遍
  再进入新状态；没有直达片段就经过 idle 拼两段（例如睡醒干活 =
  `sleeping-to-idle` + `idle-to-working`）。角标和名牌立即切换，只有画面等片段播完。
  减少动态效果时不播。当前有：GLM `idle↔working`（翻书），MiniMax `idle↔working`
  （拿板 / 放板）、`idle↔sleeping`（坐下 / 起身）。

第二批（未实现，规格见 contract §2）：`waiting`（等待审批）、`wake`
（睡醒）、`stumble`。

## C. 额度压力（代码叠加，**不需要出图**）

额度数据来自 dsh-quota-hub，取最紧张的那个窗口：

| 压力 | 条件 | 表现 | 角标（无动作角标时） |
|---|---|---|---|
| ok | 已用 < 70 % | 铭牌绿色百分比 | — |
| warn | 已用 ≥ 70 % | 铭牌橙色百分比 | ⚠️ |
| critical | 已用 ≥ 90 % | 整图变灰；**气泡常驻**「快没电啦 X%！N 后重置」 | 💧 |
| ghost | 该家未配 Key / 已停用 | 半透明 + 全灰；铭牌「无Key / 停用」 | 💤 |
| unknown | 查询失败 / 没装 quota-hub | 略透明；气泡显示原因 | ❓ |

动作角标（⚡ ❌ ✅ 💤）优先于压力角标。角标盖在右上角 18 % × 18 % 区域，
所以这个角在每一帧都必须全透明（contract §4）。

## D. 手动交互

| 操作 | 效果 |
|---|---|
| 悬停 | 气泡：已用 % · 窗口名 · 重置倒计时 |
| 单击 | 跳两下 + 立即刷新额度 |
| 拖拽 | 跟手移动（> 4 px 算拖拽），松手记住位置 |
| 右键 | 菜单：临时预览形象（只在内存里，刷新即失效）/ 恢复默认形象 / 大小 64→88→112 px / 重置位置 / 开发者状态循环预览 / 关于 |
| 切回标签页 | 立即刷新额度、素材清单和运行结果 |

位置和大小所有宠物共用，存在 localStorage；不存图片。

## E. 刷新节奏

- 额度、素材清单：每 30 s（仅页面在前台时）。
- 运行结果（`/dsh-quota-pets/events.json`）：运行中、结束后约 5 s 内、以及出错状态期间每 2 s；
  切换会话时立即查一次。
- 宿主每 3 s 重扫 `assets/`，放入新图后刷新页面即生效。
