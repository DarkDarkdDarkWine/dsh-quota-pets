# dsh-quota-pets 桌宠能力清单

> 给形象/动作设计用的对照表：桌宠现在「会什么、什么条件触发、
> 表现在哪」。设计动作时对着这张表填空即可。
> 文中「CSS 动作」= 插件自动施加的整体动画/滤镜，出静态图也有；
> 「图内动画」= 需要你出 GIF/APNG/WebP 动图才有的效果。

## A. 自动状态机（不用你管，自动切换）

| # | 状态 | 触发条件 | 默认表现（CSS 动作） | 角标 | 铭牌/气泡 | 对应形象文件 |
|---|------|----------|---------------------|------|-----------|--------------|
| 1 | 常态 ok | 额度已用 <70% | 轻盈上下浮动（3.2s 循环） | 无 | 绿色百分比；悬停出气泡 | `<provider>.png` |
| 2 | 焦虑 warn | 已用 ≥70% | 左右摇摆（1s 循环） | ⚠️ | 橙色百分比 | `<provider>.warn.png`（缺则回退常态图） |
| 3 | 躺平 critical | 已用 ≥90% | 旋转 94° 躺倒 + 呼吸缩放 + 变灰 | 💧 | 红色百分比；**气泡常驻**「快没电啦 X%！N 后重置」 | `<provider>.critical.png`（缺则回退） |
| 4 | 干活 work | 当前会话 running 中 | 快速小幅抖动敲键盘节奏（0.34s 循环），覆盖常态/焦虑/躺平动画 | ⚡ | 铭牌不变 | `<provider>.work.png`（缺则按当前状态回退） |
| 5 | 高亮 active | 宠物 = 当前会话模型 | 金色光晕（drop-shadow），叠加在任何状态上 | — | — | 用当前状态图 |
| 6 | 幽灵 ghost | 该家未配 Key / 已停用 | 半透明 + 全灰 + 慢浮动 | 💤 | 铭牌显示「无Key / 停用」 | 用基础图（滤镜变灰） |
| 7 | 未知 unknown | 额度查询失败 / quota-hub 不在 | 略透明 + 慢浮动 | ❓ | 铭牌「?」；气泡显示错误原因 | 用基础图 |

**状态叠加规则**：显示哪只由「当前模型」决定（同一时刻只显示一只）；
这只宠物的动画优先级 `work > critical > warn > ok`；光晕、变灰、透明
是滤镜，和任何动画叠加。

## B. 手动交互（用户操作）

| 操作 | 效果 | 设计素材对应 |
|------|------|--------------|
| 单击 | 跳两下（hop 0.55s）+ 立即刷新额度数据 | 可出点击/欢呼 GIF 变体（未来挂 `.click.png`，现未实现） |
| 悬停 | 气泡浮现：已用 % · 最紧张窗口名 · 重置倒计时 | 无需素材 |
| 拖拽 | 跟手移动（>4px 判定拖拽），松手记住位置 | 拖拽中会暂停浮动动画 |
| 右键 | 菜单：换形象 / 恢复默认形象 / 大小（64→88→112px 循环）/ 重置位置 / 关于 | 无需素材 |
| 切回页面标签页 | 自动刷新一次额度和形象清单 | — |
| 定时 | 每 30s 自动轮询（页面前台时） | — |
| 切换模型 | 旧宠淡出 → 新宠淡入（0.25s）；新宠可用默认驻点 | 入场动画未来可做（见 D） |

## C. 气泡文案规则（自动）

- critical：`快没电啦 92.3%！5 时 12 分后重置`（常驻 + 轻微脉动）
- 其它悬停：`GLM 已用 45.1% · 5h窗口 · 3 时 20 分后重置`
- 错误：`GLM：HTTP 401 …`／未配 Key：`还没配 Key，查不了额度`

## D. 形象素材规格

- 文件命名：`<provider>[-状态].png`，provider ∈ `glm | minimax | kimi | deepseek`，
  状态 ∈ `warn | critical | work`（基础形象不带后缀）。
- 回退链：`work → critical → warn → base → 内置 SVG 占位`。
- 扩展名支持 `png / apng / gif / webp / svg / jpg`；**想要图内动画就用
  GIF / APNG / 动图 WebP**（CSS 动作照样叠加在整张图上）。
- 尺寸：显示宽 64 / 88 / 112px 三档（用户可切），图片等比缩放；
  建议出图 512–1024 宽、透明底、竖构图、全身、脚下留白。
- 投放方式：扔进插件 `assets/` 目录（≤30s 自动生效，无需刷新），
  或右键「换形象…」选本地图（≤1.5MB，存浏览器）。

## E. 设计建议（每只出几张、动作怎么给）

| 素材 | 建议动作（图内动画） | 循环节奏 |
|------|---------------------|----------|
| base | 呼吸起伏、眨眼、待机小动作（捧东西摸摸、耳朵抖） | 2–4s 循环 |
| warn | 焦虑踱步 / 绞手 / 冒汗珠、眼神飘 | ~1s 循环 |
| critical | 躺倒、眼睛变 ><、灵魂出窍般慢呼吸（CSS 还会把她转躺+变灰） | 3–4s 循环 |
| work | 手部快速敲击、头微点、干劲小火苗 | 0.3–0.5s 循环 |

注意：critical 图**不必自己画躺倒**（CSS 会旋转+变灰），画「瘫软没劲
的表情姿势」即可；如果你出的图自带躺倒构图，告诉我把 CSS 旋转关掉。
